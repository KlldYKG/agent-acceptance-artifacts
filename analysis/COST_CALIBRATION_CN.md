## 三、全矩阵外推（正式口径，2026-11-17 修正版）

矩阵 = 2 agent × 2 模型档 × 3 臂 × 3 重复 × **5 链** = **180 次链运行 ≈ 1800 任务实例**
（初版漏乘链数，已修正）。

- A0：60 链运行 → 600 次 agent 调用（1 轮/任务）；
- A1 / A-full：各 60 链运行 → 各 ≈960 次调用（1 + REJECT×60% 修复轮）；
- 合计 ≈ **2520 次 agent 调用**；门控本地运行，API 成本为零。

**v4-pro 系数已实测（C4 同任务）**：$0.0342 vs flash $0.0055 = **6.2×**，且耗时更短
（52.5s vs 83s）。

| 方案 | API 成本 |

## 四、墙钟外推（比钱更紧的约束）

- flash/OpenCode：34 min/链运行；aider 与 OpenCode 单任务耗时相近（229s vs 204s 均值）
  但整链略慢（修复轮 + gate 开销）；
- 全矩阵串行 ≈ **120 h**，必须并行：
  - 约束：opencode 的 sqlite 用量通道按"时间窗内最新会话"取值，**并行运行会串号**
    → opencode 任务必须单 worker 串行；
  - aider 用量取自自身 stdout，并行安全 → 可 2 worker 分片；
  - 建议布局 = 1×opencode + 2×aider 三 worker，RQ1-flash 批 ≈ **9~15 h**。
